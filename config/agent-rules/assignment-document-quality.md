# Assignment and printable-document quality

Apply these rules whenever a task creates, adapts, audits, or renders an assignment,
workbook, evidence pack, PDF, or other printable document.

1. Treat an operator-named reference file as authoritative. Inspect it before editing and
   record its learner, centre, unit, dates, page count, page size, sections, and evidence
   parts. “Same as” means preserve those properties except fields the operator explicitly
   asks to personalise.
2. For scanned or image-only PDFs, inventory every page before answering. List every
   question and sub-question across all question sets; do not stop after the first clear set.
   Exclude only assessor/admin forms that are intentionally hand-completed.
3. Build a source-of-truth table for learner identity, centre, unit, activity date,
   compilation date, theme, and allowed fictional fields. Never silently replace a
   reference date with today. Fictional child names or initials are allowed only when the
   operator permits them, and must remain anonymised and internally consistent.
4. Answer every inventoried prompt in the requested voice. Before rendering, scan for
   blanks, placeholders, stale learner/centre names, contradictory dates, unsupported
   claims, duplicated sections, and inconsistent development-area counts.
5. Generated images are illustrative, not proof of a real event. Inspect every image after
   generation. Reject any image with the wrong age group, country/context, activity,
   visible person name, school grade, date, logo, or text. Never call generated imagery
   genuine, documentary, or actual classroom evidence.
6. Match every image and evidence sheet to the written activity, learner, centre, and date
   range. If genuine evidence is required but unavailable, use a clearly labelled
   placeholder or ask for source material; do not fabricate provenance.
7. Render the final artifact and verify it, not only its source: exact page count and page
   size, readable text, embedded images, expected first/last sections, and no clipped or
   blank content. Compare the rendered result side by side with the named reference.
8. Report separate receipts for content completeness, reference parity, image inspection,
   and render verification. Do not claim “matches”, “complete”, or Confidence above 8
   until all four checks pass.
