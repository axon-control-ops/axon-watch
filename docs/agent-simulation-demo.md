## Why this matters

Cursor keeps agent conversation in the chat panel. The center editor is reserved for project files. Axon-X now follows the same split:

- Agent prose stays in the thread.
- Only workspace files (like this one) open in the editor.
- Long reports can still be opened manually via **Open in editor** — opt-in only.

## Sample section
