# Verify latency evidence fixtures

These files support `scripts/verify/check_latency_budget.py`.

| File | Purpose |
|---|---|
| `shell-boot-report.dev.json` | Dev placeholder under nightly threshold until browser automation lands |
| `runtime-summary-latency.json` | Generated by `./scripts/dev/collect-verify-evidence.sh` |
| `watch-summary-latency.json` | Generated by `./scripts/dev/collect-verify-evidence.sh` |

Collect live evidence when the stack is running:

```bash
./scripts/dev/up.sh
./scripts/dev/collect-verify-evidence.sh
./scripts/dev/verify-with-evidence.sh
```

Or export env vars for `npm run verify`:

```bash
export AXON_WATCH_SHELL_BOOT_REPORT=scripts/verify/fixtures/shell-boot-report.dev.json
export AXON_WATCH_RUNTIME_SUMMARY_URL=http://127.0.0.1:8787/api/runtime/summary
```
